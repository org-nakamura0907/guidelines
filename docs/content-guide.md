# コンテンツガイドライン

コンテンツ（Markdown / MDX ファイル）を作成・編集する際のガイドラインをまとめたドキュメント。

---

## 見出し

| レベル | 用途                    | 使用可否                                  |
| ------ | ----------------------- | ----------------------------------------- |
| h1     | ページタイトル          | **禁止**（frontmatter の `title` を使用） |
| h2     | ページ内の大セクション  | **推奨**                                  |
| h3     | h2 配下のサブセクション | **推奨**                                  |
| h4〜h6 | —                       | **禁止**                                  |

**h1 を禁止する理由**

ページタイトルは frontmatter の `title` フィールドで管理しており、コンテンツ本文内に h1 を書くと重複する。

**h4 以下を禁止する理由**

目次（ToC）は h2・h3 のみを対象とするため、h4 以下のセクションには ToC からジャンプできない。また、見出しが深くなる場合はページの分割を検討する。

**レベルをスキップしない**

見出しレベルは順番に使用する。h2 の次に h4 を使うといったスキップは禁止。

```markdown
<!-- NG -->

## セクション

#### サブセクション

<!-- OK -->

## セクション

### サブセクション
```

**ページ分割の目安**

h3 がひとつの h2 配下に4つ以上並ぶ場合、そのセクションは独立したページへの分割を検討する。
